# Return and Refund Policy

## Return window

Returns are accepted within 30 days of the delivery date. The 30-day period starts on the date the order was delivered, not the date the order was placed. Requests made after 30 days are not eligible for an automatic refund and are escalated to a support agent for review.

Orders that have not been delivered do not have a return window. A customer who wants to stop an undelivered order is requesting a cancellation, which is handled separately.

## Refund amounts

Refunds of 500 or less are approved automatically when all other conditions in this policy are met. Refunds above 500 are never approved automatically and are always escalated to a support agent for review, regardless of the reason given.

The refund amount is the line total of the item being returned. Shipping charges are not refunded.

## Return reasons

A return is eligible for an automatic refund when the reason is Damaged or Wrong item.

A return for the reason Not as described is escalated to a support agent, because it requires a judgement about the product listing.

A return for the reason Changed mind is escalated to a support agent, because it is a discretionary return rather than a fault on our side.

## Non-returnable items

Some items are marked as non-returnable at the time of purchase. These items cannot be returned for any reason and are not eligible for an automatic refund. A request to return a non-returnable item is escalated to a support agent, who can confirm whether an exception applies.

## Refund processing time

An approved refund is issued to the original payment method within 3 business days. The customer's bank may take additional time to show the credit.

## Order cancellations

Order cancellations are not processed automatically. Every cancellation request is escalated to a support agent with the order details, regardless of the order status or amount.

## When a request is escalated

A return or refund request is escalated to a support agent when any of the following is true.

The requested refund amount is above 500.

The order was delivered more than 30 days ago.

The order does not belong to the person making the request.

The item is marked as non-returnable.

The return reason is Not as described or Changed mind.

When a request is escalated, a case is created with the order details and the reason for escalation, and the customer is told that a support agent will follow up.
